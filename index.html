01Problem Statement

Where a voice assistant sits changes how we speak to it.

Voice assistants like Alexa and Google Assistant are widely used, but their placement and visibility can impact user interaction. While visible assistants provide a tangible reference point, invisible voice assistants—embedded in the environment (e.g., walls, ceilings, corners)—lack a physical presence, potentially altering how users engage with them.

This study evaluates how users interact with visible vs. invisible voice assistants, measuring changes in interaction behavior, usability, and user experience to determine which setup is more intuitive and user-friendly.

02Research Questions

Four questions drove the study.

  1. How does user interaction differ between visible and invisible voice assistants?
  2. Which design enhances usability and user comfort?
  3. What usability challenges arise in each scenario?
  4. How does the absence of a physical reference point impact voice interactions?
03Literature Review

Four theories frame the question.

  1. Gibson’s AffordancesDoes visibility provide clearer affordances for interaction?
  2. Norman’s Concept of Mental ModelsUsers form expectations about system responses based on visibility.
  3. Fitts’ LawDoes the lack of a physical target affect interaction efficiency?
  4. Embodied Cognition TheoryHow does spatial perception influence voice-based interaction?

User Behavior

Invisible AssistantsInitial hesitation is common, with users feeling a lower sense of control. Some found it awkward to speak without a visible reference, while others actively searched for the source of responses. A few users multitasked while interacting but remained attentive to replies. Task completion times were generally longer.

Visible AssistantsUsers engage more quickly, demonstrating awareness of the device’s performance. Task errors are minimal, and some users naturally face the device while speaking. Overall, trust in the system is higher.

10Inferences

What the evidence suggests.

Visibility Affects Usability & Confidence

Users feel more confident interacting with visible voice assistants because they can see where the response is coming from. Invisible assistants (embedded in walls/ceilings) create initial hesitation as users struggle to determine if the system is listening.

Mental Model & Affordance Impact Interaction

Users expect visible assistants to function like physical devices and interact with them accordingly. With invisible assistants, users lack physical cues, leading to trial-and-error interactions before they adjust.

Task Performance & Error Rate

Faster task completion & fewer errors with visible assistants due to clear affordances. Higher cognitive load with invisible assistants as users must remember where to direct their voice and verify responses.

Perceived Control & User Trust

Visible Assistants: Users feel they have more control and can easily disengage if needed. Invisible Assistants: Some users feel discomfort due to the lack of physical presence, leading to lower trust in the system.
