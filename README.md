# Evaluating User Interaction with Voice Assistants: Visible vs Invisible

An HCI research project on how the physical presence of a voice assistant
changes the way people interact with it.

**View the case study:** https://preksha-05.github.io/Voice-Assistant-Research/

## About the study
Voice assistants like Alexa and Google Assistant are increasingly embedded in
walls, ceilings and corners. This study asks how the absence of a physical
reference point affects interaction behavior, usability and user comfort.

## Methods
- Literature review: affordances, mental models, Fitts' Law, embodied cognition
- Pilot study with 30 participants across two scenarios
- Observational study with participant sketches
- Personal interviews
- Data analysis and inferences

## Key findings
- Invisible assistants disturbed participants less, but more of them felt uneasy.
- Visible assistants drew more orientation toward the device and higher trust.
- Participants imagined many different systems behind an invisible assistant.
